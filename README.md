# FRAME Studio — GitHub Pages beta preview

This folder contains a static HTML beta-preview build of FRAME Studio. It does not contain customers' original photos or proprietary PDF documents.

- Upload and image processing use browser-local file operations.
- Automatic AI segmentation requires a reachable third-party model runtime and has **not** passed quality validation; output is not production-certified.
- Nykaa PDF size references are limited and some products remain unverified.
- Three composition layouts and project saving are experimental.
- The beta is not a commercial product and must remain blocked from search engines.
- GitHub Pages supports static HTML/JS, **not** FRAME's FastAPI backend. A backend-enabled commercial product will require separate hosting.

Deployment: place these files at the root of an appropriate dedicated GitHub repository and enable GitHub Pages for the main branch root in repository Settings -> Pages.
